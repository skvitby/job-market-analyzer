# Протокол приёмочного тестирования US-01 — US-03

**Объект тестирования:** CLI `job-market-analyzer` (коммит `307fa78`)
**Тип:** приёмочное тестирование по Acceptance Criteria ([requirements.md](../../requirements.md))
**Окружение:** Windows 10, Python 3.14 (venv), PowerShell; HH API через curl вне VPN; LLM — Claude Haiku 4.5 (`vacancy_analysis`, `cv_processing`)
**Тестовые данные:** выгрузка от 23.09.2026 (887 вакансий РФ/РБ) + догрузка по Беларуси; резюме `profile/my_cv.md`
