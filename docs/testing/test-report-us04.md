## 4. Итог первого прогона

**Результат:** 13 тест-кейсов — ✅ 8, ⚠️ 1, ❌ 3, ⏳ 1. **US-04 не принята.**

Техническая часть работает по AC: получение вакансии, версии, язык `auto`, блоки файла, проверка цитат, отсутствие подписи, объём. Не выполняется содержательное требование AC 4.3: модель Claude Haiku 4.5 при правильных цитатах в таблице соответствий приукрашивает их в тексте письма, намекает на неподтверждённое и округляет стаж. Программная проверка цитат (AC 4.6) такие отклонения не ловит — они возникают между цитатой и фразой письма.

**Порядок исправлений** (по одному, после обсуждения каждого):
1. **D-1, D-2, D-3** — достоверность текста письма.
2. **D-4** — ложные пункты в списке «без подтверждения».
3. **Z-1…Z-4** — стоп-лист и промпт.

**Регрессия после исправлений:** повторная генерация по тому же набору (TC-1…TC-11), затем ручная вычитка (TC-13).

Спорная отметка — «V&S, SDD, ПМИ, ПСИ» совпало с UAT из резюме (для «возможно» допустимо). Контрольный прогон через `scripts/eval_cover_letters.py` (Haiku, БелВЭБ): отмечены Agile, BPMN, UML — модель сама приписала к ним «упомянуты в навыках».
