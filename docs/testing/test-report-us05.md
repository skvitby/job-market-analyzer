# Протокол приёмочного тестирования US-05

**Объект тестирования:** команда `cv-tips` CLI `job-market-analyzer` (коммит `60c66b4`)
**Тип:** приёмочное тестирование по Acceptance Criteria US-05 ([requirements.md](../../requirements.md), AC 5.1–5.5, раздел «Приёмка»)
**Окружение:** Windows 10, Python 3.14 (venv), Git Bash; LLM `cv_processing` — Claude Haiku 4.5; промпт [prompts/cv_tips.md](../../prompts/cv_tips.md)
**Тестовые данные:** резюме `profile/my_cv.md`; набор приёмки US-04 — вакансии Минска из кэша `data/details/`:

| Вакансия | ID | Зачем в наборе |
|---|---|---|
| Middle Business Analyst — Itransition | 137493556 | Англоязычная вакансия: «стало» на английском |
| Системный аналитик управления ИТ и корпоративной архитектуры — Банк БелВЭБ | 136902181 | Банковский домен, которого нет в резюме: много пробелов |
| Бизнес-аналитик / Системный аналитик — Лайфтех | 137587921 | Хорошее совпадение с опытом; на ней шла разработка — есть версии v1–v4 |

**Участники:** бизнес-аналитик (решения по спорным случаям, оценка пользы), Claude Code (прогоны, сверка советов с резюме и вакансией)
**Стоимость:** прогон набора на Haiku 4.5 — 3 запроса, ~15 тыс. входных и ~2,4 тыс. выходных токенов, около $0,03; контрольный прогон на Sonnet 5.5 — ~16 тыс. и ~12 тыс. токенов, порядка $0,2 (оценка по токенам); пробные вызовы в ходе разработки (Лайфтех, 3 раза) — около $0,03

## 5. Решение

По договорённости интервью по требованиям US-05 (Q11) и решению пользователя 30.09.2026:

- **Техническая часть US-05 принята** (TC-1…TC-11, TC-16).
- **Приёмка содержания отложена** до новой версии Claude Haiku — вместе с US-04 (бэклог, п. 16). Эталон — файлы Sonnet 5.5 (раздел 4).
- Модель `cv_processing` не меняется. Для важного отклика `cv_processing` можно разово переключить на `claude-sonnet-5-5`.
- До этого советы Haiku использовать с ручной проверкой по [руководству](../user-guide/cv-tips.md): отметки ⚠️ ловят часть проблем (C-3, C-4), усиление формулировок (C-1, C-2) — только вычитка.
