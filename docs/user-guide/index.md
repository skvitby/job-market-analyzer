# Руководство пользователя job-market-analyzer

CLI-инструмент для соискателя на позицию бизнес/системного аналитика: собирает вакансии с HH.ru, показывает, какие навыки востребованы и каких не хватает в резюме, готовит черновики сопроводительных писем и советы по адаптации резюме под конкретную вакансию.

> [!note] Как читать руководство
> Впервые — по порядку: «Установка» → «Настройки» → «Типовой сценарий». Дальше — главы по командам как справочник. Если что-то не работает — сразу в «Частые проблемы»: там собраны реальные тексты сообщений программы.

## Что умеет программа

| Что | Команда | Результат | User Story |
|---|---|---|---|
| Все настройки в одном файле: фильтры поиска, словарь навыков, LLM, параметры писем | — | `profile/preferences.json` | US-01 |
| Выгрузка вакансий с HH.ru и полных описаний | `fetch` | `data/raw_vacancies_{время}.json`, `data/details/{id}.json` | US-02 |
| Востребованные навыки рынка и сравнение с резюме (Gap Analysis) | `analyze` | `reports/market_skills_summary.md` | US-03 |
| Черновик сопроводительного письма под вакансию | `cover-letter <id>` | `reports/cover_letters/cl_{id}.md`, `_v2`, `_v3` … | US-04 |
| До 5 советов, как назвать опыт из резюме словами вакансии | `cv-tips <id>` | `reports/cv_tips/cv_tips_{id}.md`, `_v2`, `_v3` … | US-05 |

`<id>` — ID вакансии, число из ссылки `hh.ru/vacancy/<ID>`.

> [!warning] Письма и советы — черновики
> Их пишет LLM, и модель по умолчанию (Claude Haiku 4.5) склонна приукрашивать опыт. Код проверяет часть утверждений по резюме и ставит отметки ⚠️, но финальная вычитка — за вами. Подробно — в главах [cover-letter](cover-letter.md) и [cv-tips](cv-tips.md).

## Основные термины

Эти слова встречаются по всему руководству.

| Термин | Что это | Где лежит / где описано |
|---|---|---|
| **Профиль** | Файл со всеми настройками программы: фильтры поиска, словарь навыков, LLM, параметры писем. «Из профиля» = из этого файла | `profile/preferences.json` — [Настройки](configuration.md#Что%20такое%20профиль) |
| **Резюме** | Ваше резюме в Markdown, с которым программа сравнивает рынок и по которому пишет письма и советы. Обезличено, в git не хранится | `profile/my_cv.md` — [Требования к резюме](configuration.md#Требования%20к%20резюме) |
| **Словарь навыков** | Список навыков с синонимами в профиле; по нему точным поиском считаются навыки в вакансиях и в резюме | Блок `analytical_skills_dictionary` профиля — [Настройки](configuration.md), раздел 2 |
| **ID вакансии** | Число из ссылки на вакансию `hh.ru/vacancy/<ID>` — параметр `<vacancy_id>` команд `cover-letter` и `cv-tips` | Адресная строка страницы вакансии на hh.ru |
| **ID региона** | Число из справочника регионов HH — параметр `--region` команды `fetch` (`16` — Беларусь, `113` — Россия) | [fetch](fetch.md#Опции) |
| **Выгрузка** | Файл с результатами одного запуска `fetch` | `data/raw_vacancies_ГГГГММДД_ЧЧММСС.json` — [fetch](fetch.md) |
| **Кэш описаний** | Полные тексты вакансий, догруженные с HH, — чтобы не запрашивать повторно | `data/details/{id}.json` — [fetch](fetch.md) |
| **Задачи LLM** | Два типа запросов к модели, для каждого в профиле своя модель: `vacancy_analysis` — навыки из вакансий; `cv_processing` — всё, где в модель уходит резюме (сравнение с рынком, письма, советы) | Поле `llm_providers` профиля — [Настройки](configuration.md), раздел 4 |
| **Пробел** | Требование вакансии или навык рынка, которого нет в резюме | [Типовой сценарий](workflow.md#Что%20делать%20с%20пробелами) |
| **Версия файла** | Письма и советы не перезаписываются: повторный запуск создаёт `_v2`, `_v3` … | [cover-letter](cover-letter.md), [cv-tips](cv-tips.md) |

## Что нужно для работы

- Windows, Python 3.11+ (проект проверялся на 3.14), PowerShell.
- Приложение HH на [dev.hh.ru](https://dev.hh.ru) и токен приложения — для `fetch` и для писем/советов по вакансиям, которых нет в локальном кэше.
- Ключ Anthropic API (или другого провайдера, или локальная Ollama) — для LLM-этапов `analyze`, `cover-letter`, `cv-tips`.
- Резюме в `profile/my_cv.md` (Markdown; раздел «Навыки» — отдельным заголовком, см. [Настройки](configuration.md#Требования%20к%20резюме)) — для сравнения с рынком, писем и советов. Файл не хранится в git.
- Obsidian — для чтения отчётов, писем и советов: они оформлены callout-блоками и чек-листами.
