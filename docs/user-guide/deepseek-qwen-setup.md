# Подключение DeepSeek и Qwen для анализа вакансий

[← к оглавлению](index.md)

> [!note] Актуальность
> Цены, названия моделей и условия проверены по официальной документации **30.09.2026**. Оба провайдера меняют условия часто (DeepSeek в 2026 году трижды: вывод старых имён моделей, пиковые часы, новая модель V4.1 Flash). Перед пополнением баланса сверьтесь со страницами из раздела «Источники».

## 1. Кратко

**Что даёт.** Задача `vacancy_analysis` (извлечение навыков из описаний вакансий) переводится на модель в 3–8 раз дешевле Claude Haiku 4.5. По умолчанию `cv_processing` (письма, советы по резюме) остаётся на Anthropic; проверка писем и советов на этих моделях — часть 2 п. 19 бэклога (`requirements.md`): резюме `profile/my_cv.md` обезличено, поэтому его можно отправлять и сюда.

**Сколько стоит.** Расчёт на ~900 входных и ~100 выходных токенов на вакансию, **без учёта режима рассуждений** (см. предупреждение ниже), $ за 1 млн токенов:

| Модель | Input | Output | ~890 вакансий | Поток за месяц (~1 800) | Дешевле Haiku |
|---|---|---|---|---|---|
| Claude Haiku 4.5 (сейчас) | 1,00 | 5,00 | ~$1,25 | ~$2,50 | — |
| **DeepSeek `deepseek-flash`** (V4.1 Flash), вне пика / пик | 0,15 / 0,30 | 0,60 / 1,20 | ~$0,17 / $0,35 | ~$0,35 / $0,70 | в 3,5–7 раз |
| **Qwen `qwen3.8-flash`** (Singapore) | 0,15 | 0,47 | ~$0,16 | ~$0,33 | ~в 8 раз |
| Qwen `qwen-flash` (старое поколение, 2025-07-28) | 0,05 | 0,40 | ~$0,08 | ~$0,15 | ~в 16 раз |
| Qwen `qwen3.7-plus` (Singapore) | 0,40 | 1,60 | ~$0,46 | ~$0,94 | ~в 2,7 раза |
| DeepSeek `deepseek-v4-pro`, вне пика / пик | 0,66 / 1,32 | 1,98 / 3,96 | ~$0,70 / $1,40 | ~$1,40 / $2,80 | в 1–2 раза |

Абсолютная экономия — около $1–2 в месяц. Основной смысл подключения — независимость от одного провайдера и сравнение качества, а не деньги.

> [!warning] Режим рассуждений (thinking) включён по умолчанию
> У `deepseek-flash`, `qwen3.8-flash`, `qwen3.7-plus` (и `qwen3.6-flash`) **thinking включён по умолчанию**. Рассуждения оплачиваются как выходные токены, поэтому выходных токенов может стать в разы больше, а реальная стоимость — выше расчёта в таблице (всё равно дешевле Haiku, но разрыв меньше). Код проекта сейчас thinking не отключает: для этого в запрос нужно передавать `extra_body` — `{"thinking": {"type": "disabled"}}` у DeepSeek и `{"enable_thinking": false}` у Qwen. Это доработка кода — п. 20 бэклога (`requirements.md`).
>
> Исключение — `qwen-flash` и `qwen-plus` (старые алиасы): у них thinking по умолчанию **выключен**, поэтому с текущим кодом они работают «как задумано».
>
> Фактический расход виден в логе запуска: строки `LLM <провайдер>/<модель>: N токенов на вход, M на выход`.

## 2. DeepSeek

### 2.1. Регистрация

1. Откройте **https://platform.deepseek.com** (адрес актуален на 30.09.2026).
2. Зарегистрируйтесь по e-mail (6-значный код подтверждения, пароль от 8 символов). По неофициальным руководствам доступны также вход через Google и регистрация по номеру телефона — **для регистрации по e-mail телефон не нужен** (по данным сторонних руководств; не подтверждено официально).
3. Письмо с кодом может попасть в «Спам».

> [!warning] Доступность из РБ — не подтверждено
> Официальная документация DeepSeek не публикует список стран. Сторонние (русскоязычные) статьи сообщают, что сайт и API из РФ работают без ограничений, а барьер — только оплата. Для Беларуси и для регистрации через Mullvad — **не подтверждено, проверить при регистрации**.

### 2.2. Пополнение баланса

- Модель оплаты — **предоплаченный баланс**, списание по факту токенов; подписки нет.
- Способы по справке DeepSeek (раздел Top Up): **PayPal, банковская карта, Alipay, WeChat Pay**. По сторонним источникам, зарубежные карты проводятся через PayPal.
- Карты банков РФ и РБ, по сторонним источникам, **обычно отклоняются**; работают карты зарубежных банков (Казахстан, Армения, Грузия и т. п.) или PayPal с такой картой. Для белорусских карт — **не подтверждено, проверить при оплате**.
- Минимальная сумма пополнения — в официальных источниках не найдена; для проекта хватит минимального платежа (~$2–5 — это месяцы работы).
- **Бесплатные токены новым аккаунтам:** официально не подтверждено. На странице цен есть понятие «granted balance» (подаренный баланс, списывается первым), но условия его выдачи не описаны. Одно стороннее руководство упоминает 5 млн токенов — **не подтверждено**, посмотрите раздел Billing после регистрации.

### 2.3. API-ключ

1. В кабинете — раздел **API Keys** → **Create new API key**, дайте имя (например, `job-market-analyzer`).
2. **Скопируйте ключ сразу** — он показывается один раз (формат `sk-…`). Потерянный ключ не восстанавливается — создаётся новый.
3. Сохраните его в файл `.env` в корне проекта (раздел 4). `.env` исключён из git (`.gitignore`) — **никогда не вставляйте ключ в `preferences.json`, код, README или скриншоты**.

### 2.4. Модели и цены (30.09.2026)

| Модель (`model`) | Версия | Контекст | Input (cache hit) | Input (cache miss) | Output | JSON |
|---|---|---|---|---|---|---|
| `deepseek-flash` | DeepSeek-V4.1-Flash (с 10.09.2026) | 1M | $0,003–0,006 | $0,15–0,30 | $0,60–1,20 | да |
| `deepseek-v4-pro` | DeepSeek-V4-Pro-0813 | 1M | $0,022–0,044 | $0,66–1,32 | $1,98–3,96 | да |

- **Пиковые часы** (с 16.08.2026): **01:00–04:00 и 06:00–10:00 UTC, пн–пт** (кроме праздников КНР). По Минску (UTC+3) — **04:00–07:00 и 09:00–13:00 в будни**. В пик цена вдвое выше; вне пика — нижняя граница диапазона.
- Старые имена `deepseek-chat` и `deepseek-reasoner` выведены 24.07.2026; `deepseek-v4-flash` пока перенаправляется на V4.1 Flash, но использовать его не стоит.
- Кэш контекста включается автоматически: повторяющаяся инструкция в начале запроса тарифицируется по цене cache hit — реальная стоимость входа немного ниже расчёта.
- **JSON-режим** поддерживается: `response_format={"type": "json_object"}`, в промпте должно быть слово «json» (в проекте выполняется — инструкция заканчивается фразой «Ответь только JSON-объектом по схеме»). Документация предупреждает, что API **изредка возвращает пустой ответ** — в проекте это приведёт к ошибке валидации пакета; вакансии пакета обработаются при следующем запуске.

### 2.5. Рекомендуемая модель — `deepseek-flash`

- Единственная дешёвая модель линейки; `deepseek-v4-pro` в 4 раза дороже, а извлечение навыков — задача на распознавание, а не на рассуждение, запас качества Pro здесь не нужен.
- Поддерживает JSON-режим и контекст 1M — пакет из 10 вакансий (~10K токенов) помещается с большим запасом.
- Запускайте анализ **вне пиковых часов** (по Минску — после 13:00, до 04:00 или в выходные) — вдвое дешевле.
- Юрисдикция данных — КНР. Для публичных вакансий приемлемо; резюме обезличено, поэтому для проверки писем и советов (часть 2 п. 19 бэклога) тоже допустимо.

## 3. Qwen (Alibaba Cloud Model Studio, International)

### 3.1. Регистрация

1. **Аккаунт Alibaba Cloud** — https://www.alibabacloud.com → Free Trial / Sign up:
   - e-mail (он же логин), пароль 8–20 символов;
   - тип аккаунта **Individual**;
   - **Country/Region** — выбирается один раз, **изменить нельзя** (определяет валюту и налоги; смена — только через удаление аккаунта). Есть ли в списке Беларусь и что будет при выборе РБ — **не подтверждено, проверить при регистрации**.
2. **Дозаполнение аккаунта** (обязательно до активации Model Studio): подтверждение **e-mail и номера телефона**, **платёжный метод** (карта или PayPal), адрес для счетов. На карте может быть временная блокировка небольшой суммы для проверки — деньги не списываются. **Виртуальные карты не принимаются.**
3. **Активация Model Studio**: откройте консоль Model Studio, в правом верхнем углу выберите регион **Singapore** (ap-southeast-1), примите соглашение — сервис активируется автоматически и начисляется бесплатная квота.

> [!warning] Телефон и карта обязательны
> В отличие от DeepSeek, для Qwen нужны **номер телефона** и **привязанная карта/PayPal** ещё до первого запроса. Принимаются ли белорусские номера и карты — **не подтверждено**. Сторонние статьи сообщают, что из РФ консоль работает нестабильно, а российские карты не проходят — нужна зарубежная карта.

> [!warning] VPN и антифрод — не подтверждено
> Официально не описано, как Alibaba Cloud относится к регистрации через VPN, когда страна выхода VPN не совпадает со страной аккаунта. Риск ручной проверки аккаунта есть; при проблемах — обратиться в поддержку.

### 3.2. Бесплатная квота

- **1 млн токенов на каждую модель, 90 дней** с момента активации Model Studio. Только для моделей региона **Singapore** с областью развёртывания **International**. Получать вручную не нужно.
- 1 млн токенов на `qwen3.8-flash` — это **~1 000 вакансий**, т. е. весь рынок Минска несколько раз можно обработать бесплатно (с thinking — меньше).
- После исчерпания квоты начинается **оплата по факту (pay-as-you-go)** с привязанной карты. Чтобы этого не случилось, включите в консоли режим **Free Quota Only** — после исчерпания API вернёт ошибку `AllocationQuota.FreeTierOnly`, и списаний не будет. В проекте это покажется как ошибка LLM, этап остановится, полученные результаты сохранятся.

### 3.3. API-ключ

1. Консоль: https://modelstudio.console.alibabacloud.com/ap-southeast-1/settings/api-key (регион **Singapore** в правом верхнем углу).
2. **Create API Key** → Workspace — по умолчанию (default), Description — `job-market-analyzer`, Permissions — **All**.
   - Ограничение по IP (**Custom**) **не включайте**: запросы идут через Mullvad, IP выхода меняется.
3. Скопируйте ключ сразу — после закрытия окна он больше не показывается.
4. Сохраните в `.env` как `DASHSCOPE_API_KEY` (раздел 4).

> [!warning] Ключ привязан к региону
> У каждого региона свои адрес, ключи и список моделей, **между регионами они не работают**. Ключ Singapore работает только с международным адресом. Ключ из региона China (Beijing) с адресом по умолчанию в проекте даст ошибку авторизации.

**Адрес API.** В проекте по умолчанию — `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`. На 30.09.2026 документация называет его устаревшим общим доменом: он **ещё работает**, но рекомендуется переход на адрес рабочего пространства `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1` (значение API Host — на странице Workspace Management). Для нового адреса нужен ключ этого же рабочего пространства. Если старый адрес перестанет отвечать — укажите новый в `base_url` (раздел 4).

### 3.4. Модели и цены (Singapore / International, 30.09.2026)

| Модель (`model`) | Что это | Input | Output | Thinking по умолчанию | JSON-режим |
|---|---|---|---|---|---|
| `qwen3.8-flash` | текущий Flash, 1M контекст | $0,15 | $0,47 (одинаково с thinking и без) | включён | да (в обоих режимах) |
| `qwen3.7-plus` (снимок 2026-05-26) | Plus, 1M контекст | $0,40 | $1,60 | включён | да (в обоих режимах) |
| `qwen3.6-flash` (снимок 2026-04-16) | прошлый Flash | $0,25 | $1,50 | включён | только без thinking* |
| `qwen-flash` (= qwen-flash-2025-07-28) | старый Flash | $0,05 | $0,40 | **выключен** | да |
| `qwen-plus` (= qwen-plus-2025-12-01) | старый Plus | $0,40 | $1,20 (без thinking) | **выключен** | да |

Цены — для запросов до 256K токенов (у проекта ~10K на пакет). *Модели с пометкой «non-thinking» принимают JSON-режим и с thinking, но, по документации, могут вернуть не строго валидный JSON.

- **JSON-режим**: `response_format={"type": "json_object"}`, в сообщениях должно быть слово «JSON» — в проекте выполняется. Режим `json_schema` в регионе Singapore пока не поддерживается — проект его для Qwen и не использует.

**Уточнение к ADR-001 (раздел 3.2).** Там «Qwen-Flash $0,15 / $0,47» — это цены текущей `qwen3.8-flash`; а «Qwen-Plus $0,40 / $1,60 (промо)» соответствует `qwen3.7-plus`, и на странице модели это **базовая**, а не промо-цена. Алиас `qwen-flash` указывает на модель 2025 года и стоит $0,05 / $0,40. Названия DeepSeek («V4.1 Flash», $0,15–0,30 / $0,60–1,20, пиковые часы) актуальны; в `model` указывается `deepseek-flash`.

### 3.5. Рекомендуемая модель — `qwen3.8-flash`

- Текущее поколение Flash по той же цене, что DeepSeek вне пика, но **без пиковых часов** и с **бесплатным 1 млн токенов** на тест.
- Цена вывода одинаковая с thinking и без — включённый по умолчанию thinking увеличит число выходных токенов, но не их цену.
- JSON-режим официально поддерживается и в режиме thinking.
- **Бюджетная альтернатива** — `qwen-flash`: в 2 раза дешевле и без thinking (сразу работает «как задумано»), но модель 2025 года — качество на русском, вероятно, ниже; имеет смысл сравнить на тех же 48 вакансиях.
- **Если качества Flash не хватит** — `qwen3.7-plus` (в 2,7 раза дешевле Haiku).

## 4. Подключение в проекте

### 4.1. Ключ в `.env`

В файле `.env` в корне проекта (не `.env.example`!) заполните нужную строку:

```dotenv
DEEPSEEK_API_KEY=sk-...
DASHSCOPE_API_KEY=sk-...
```

`ANTHROPIC_API_KEY` оставьте — он нужен для `cv_processing`.

### 4.2. `profile/preferences.json` → `llm_preferences.llm_providers`

**Вариант DeepSeek:**

```json
"llm_providers": {
  "vacancy_analysis": {"provider": "deepseek", "model": "deepseek-flash"},
  "cv_processing":    {"provider": "anthropic", "model": "claude-haiku-4-5"}
}
```

**Вариант Qwen:**

```json
"llm_providers": {
  "vacancy_analysis": {"provider": "qwen", "model": "qwen3.8-flash"},
  "cv_processing":    {"provider": "anthropic", "model": "claude-haiku-4-5"}
}
```

**Qwen с адресом рабочего пространства** (если старый адрес перестал работать):

```json
"vacancy_analysis": {
  "provider": "qwen",
  "model": "qwen3.8-flash",
  "base_url": "https://<WorkspaceId>.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1"
}
```

> [!warning] `cv_processing` — пока не менять
> По умолчанию `cv_processing` остаётся `anthropic` (или локальная `ollama`). Письма и советы на DeepSeek и Qwen сначала проверяются на наборе приёмки против эталона Claude Sonnet 5.5 (часть 2 п. 19 бэклога) — переключать только по результатам этой проверки.

### 4.3. Проверка

1. **Сохраните копию кэша** — `--llm-refresh` перезапишет результаты Haiku по этим вакансиям, и сравнить будет не с чем. В PowerShell из корня проекта:

   ```powershell
   Copy-Item data\llm_skills_cache.json data\llm_skills_cache.haiku.json
   ```

2. Запустите анализ (на DeepSeek — лучше вне пиковых часов):

   ```powershell
   .venv\Scripts\python.exe -m src.cli analyze --area Минск --llm-refresh
   ```

3. **Что ожидать:**
   - в логе — `LLM deepseek/deepseek-flash: отправляю N вакансий, M запросов` (или `qwen/qwen3.8-flash`), затем по каждому пакету — число токенов и `пакет k/M готов`;
   - в конце — `Готово: в отчёте N вакансий → reports\market_skills_summary.md`;
   - в `data/llm_skills_cache.json` у вакансий поля `"provider"` и `"model"` сменятся на новые;
   - сравнение с резюме в этом же запуске по-прежнему выполняет Claude (`cv_processing`) — это небольшой расход на Anthropic;
   - если какой-то пакет вернулся без части вакансий — предупреждение `LLM не вернул результат по вакансиям …`; они обработаются при следующем запуске без `--llm-refresh`.
4. **Проверьте выходные токены** в логе: если их на порядок больше ~100 на вакансию — работает thinking (см. предупреждение в разделе 1).

**Типичные ошибки** (проект переводит их в понятные сообщения):

| Сообщение | Причина |
|---|---|
| `В .env не задан DEEPSEEK_API_KEY` / `DASHSCOPE_API_KEY` | ключ не записан в `.env` или опечатка в имени |
| `Ключ … недействителен или истёк` | неверный ключ; у Qwen — ключ не того региона |
| `Модель … не найдена у провайдера` | опечатка в `model` или модель недоступна в регионе |
| `Закончился баланс …` | нет средств на балансе DeepSeek |
| ошибка с `AllocationQuota.FreeTierOnly` | закончилась бесплатная квота Qwen при включённом Free Quota Only |
| `Ответ … обрезан по лимиту токенов` | длинные рассуждения (thinking) исчерпали лимит ответа — уменьшите `batch_size` (например, `"batch_size": 5`) |
| `Нет соединения с …` | проблема сети/VPN |

> [!warning] Сеть: HH вне VPN, LLM — через VPN
> Запросы к HH идут через `curl`, исключённый из Mullvad (`HH_CURL_PATH`), — это касается `fetch`. Запросы к LLM выполняет сам Python, поэтому они идут **через Mullvad**. Если провайдер отвергает запросы с IP VPN — **не подтверждено**, при ошибках соединения/доступа попробуйте сменить сервер Mullvad.

## 5. Итоговая рекомендация

**Первой пробовать Qwen `qwen3.8-flash`:**

1. **Бесплатный тест** — 1 млн токенов на 90 дней хватает, чтобы прогнать тот же набор из 48 вакансий Минска (как в ADR-001, раздел 6.1) и сравнить с Haiku, не заплатив ничего; режим Free Quota Only гарантирует отсутствие списаний.
2. **Самая низкая цена среди моделей текущего поколения** (~$0,33 в месяц) и **без пиковых часов** — у DeepSeek пик приходится на рабочее утро по Минску.
3. JSON-режим официально поддерживается и с thinking.

**Запасной вариант — DeepSeek `deepseek-flash`**, если регистрация в Alibaba Cloud не пройдёт (нужны телефон и карта, строгая проверка аккаунта): регистрация проще (только e-mail), но нужна оплата PayPal/зарубежной картой и нет подтверждённой бесплатной квоты.

**Что сделать до массового использования:** добавить в код отключение thinking для DeepSeek и Qwen (п. 20 бэклога) — это уменьшит выходные токены и время ответа и снизит риск обрезания ответа.

## 6. Не подтверждено — проверить при регистрации

- Регистрация и работа API **из Беларуси** и **через Mullvad** — у обоих провайдеров.
- Приём **белорусских карт** (DeepSeek, Alibaba Cloud) и **белорусского номера телефона** (Alibaba Cloud); наличие Беларуси в списке стран Alibaba Cloud.
- **Бесплатный баланс** для новых аккаунтов DeepSeek и минимальная сумма пополнения.
- Сроки отключения старого адреса `dashscope-intl.aliyuncs.com` (официально — «ещё доступен, рекомендуется миграция»).
- Качество на русском: официальных сравнений `deepseek-flash` и `qwen3.8-flash` на русском нет — проверяется только прогоном на своих вакансиях.
