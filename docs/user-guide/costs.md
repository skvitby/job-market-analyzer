# Стоимость работы с LLM

[← к оглавлению](index.md)

Платные только LLM-запросы. `fetch` и `analyze --no-llm` бесплатны. Оплата Anthropic — предоплатой в Anthropic Console, отдельно от подписки Claude.

## Сколько стоит (Claude)

Фактические данные прогонов ([ADR-001](../adr/001-llm-provider.md), протоколы приёмки, [STATUS](../STATUS.md)):

| Операция | Haiku 4.5 (по умолчанию) | Sonnet 5.5 |
|---|---|---|
| `analyze`, первая обработка 48 вакансий Минска | ~$0,07 (5 запросов, ~44 тыс. входных токенов) | — |
| `analyze` после `fetch`: 4 новые вакансии + пересчёт сравнения с резюме | ~$0,02 | — |
| `analyze` повторно на тех же данных | $0 — всё из кэша | — |
| Пересчёт сравнения с резюме (сменились фильтры, резюме, словарь) | ~$0,01 | — |
| `cover-letter`, одно письмо | ~$0,01 | ~$0,04 |
| `cv-tips`, одна вакансия | ~$0,01 | порядка $0,07 |

Оценки на объём рынка (ADR-001, ~900 входных и ~100 выходных токенов на вакансию):

| Объём | Haiku 4.5 |
|---|---|
| ~890 вакансий РФ + РБ — первая обработка | ~$1,25 |
| Поток новых вакансий за месяц (~1 800) | ~$2,50 |

Для сравнения: вся разработка и тестирование проекта обошлись в Claude API примерно в $1,2.

> [!tip] Где видно фактический расход
> В логе каждого запроса: `LLM <провайдер>/<модель>: N токенов на вход, M на выход`. Цены за 1 млн токенов — в [ADR-001](../adr/001-llm-provider.md), раздел 3.

## Как снизить

| Способ | Экономия | Цена вопроса |
|---|---|---|
| Кэши — не сбрасывать без нужды | Повторный `analyze` бесплатен; в LLM уходят только новые вакансии | `--llm-refresh` и порча `data/llm_skills_cache.json` = повторная оплата |
| `analyze --no-llm` | Бесплатно | Нет навыков вне словаря и сравнения с резюме |
| Фильтры `--area`, `--days` | Меньше вакансий — меньше запросов на первой обработке | Но смена фильтров пересчитывает сравнение с резюме (~$0,01; бэклог, п. 11) |
| DeepSeek или Qwen для `vacancy_analysis` | В 3–8 раз дешевле Haiku на анализе вакансий; в абсолютных цифрах — около $1–2 в месяц | Регистрация и оплата зарубежной картой, качество не проверено на своих данных (бэклог, п. 19); с включённым по умолчанию thinking реальный расход выше расчётного (п. 20). Инструкция — [подключение DeepSeek и Qwen](deepseek-qwen-setup.md) |
| Ollama (локально) | Бесплатно, данные не покидают компьютер | Качество и скорость заметно ниже: для вакансий — ~11 мин вместо ~1 мин на 48 вакансиях и пропуски, для писем модель 4B не подходит ([ADR-001](../adr/001-llm-provider.md), раздел 6) |
| Sonnet — только разово | Письма и советы на Haiku дешевле в 4–7 раз | Нужна тщательная вычитка ([cover-letter](cover-letter.md#Когда%20переключать%20модель%20на%20Sonnet)) |

**Вывод:** при обычной работе (регулярный `fetch` + `analyze` по одному региону, несколько писем и советов в неделю) расходы на Haiku 4.5 — центы в неделю (оценка по данным прогонов, не измерение). Экономить имеет смысл не на модели, а на лишних пересчётах; а на важных откликах — наоборот, не экономить и брать Sonnet.
