# Прототип веб-интерфейса (US-06)

Кликабельный прототип будущего локального веб-интерфейса job-market-analyzer. Требования — [US-06 в requirements.md](../../requirements.md#us-06-локальный-веб-интерфейс-web-ui), бриф — [brief.md](brief.md).

## Как открыть

Скачать [`index.html`](index.html) и открыть двойным кликом в браузере. Сервер, установка и интернет не нужны (без интернета шрифт Golos Text заменится системным).

## Экраны

| Экран | Что показывает |
|---|---|
| Обзор рынка | KPI, полоса «чем рынок покрыт резюме», рейтинг навыков (цвет — статус в резюме), навыки, не встретившиеся ни в одной вакансии |
| Gap-анализ | Сравнение с резюме: частота, статус, цитата; навыки вне словаря, найденные LLM |
| Вакансии | 59 вакансий Минска, фильтры; вкладка «Выгрузки» — история `data/raw_vacancies_*.json` |
| Карточка вакансии | Соответствие резюме по навыкам словаря, описание, письмо и советы с версиями и моделями |
| Резюме | Метаданные `profile/my_cv.md`, устаревшее сравнение, разделы, которые читает инструмент |
| Настройки | Поиск вакансий, словарь навыков (редактирование), модели LLM, письмо, подключения |

Запуск команд (`fetch`, `analyze`, `cover-letter`, `cv-tips`) имитируется в консоли внизу экрана: прогресс, лог с эквивалентной командой CLI, состояния «Готово», «Готово, есть предупреждения», «Ошибка», «Отменено».

**Переключатели «Демо»** в левой панели (на мобильном — кнопка «Тема и демо»): «команды завершаются ошибкой» и «резюме не найдено». Они показывают сценарии сбоя и пустые состояния и в продукт не входят.

## Ограничения прототипа

- У вакансий без своего содержимого все версии письма показывают один и тот же шаблонный текст; номера версий и модели при этом реальные.
- Версии советов отличаются только номером и моделью, содержимое одинаковое.
- Имитация `fetch` всегда повторяет результат последней выгрузки: «Найдено 22 вакансии, новых 7».
- У новой выгрузки колонка «В отчёте» остаётся «после анализа» и после повторного анализа: честной цифры для повторённых данных нет.
- Повторный анализ не меняет цифры рынка — меняются только дата сравнения с резюме и модель в подписях.
- Изменения (настройки, словарь, новые версии) живут в памяти страницы и сбрасываются при перезагрузке; сохраняются только тема и вид экрана.

## Сценарные прогоны

В папке [`tests/`](tests/) — 12 сценариев. Каждый кликает по прототипу в headless Chrome и печатает фактические значения. Прогон падает, если сценарий не дошёл до конца, поймал исключение или на странице была ошибка JavaScript. Ожидаемые значения в сценариях не зашиты, вывод сверяется глазами.

Запуск из корня проекта (нужен установленный Chrome или Edge; путь можно задать переменной `CHROME`):

```
python docs/prototype/tests/run_tests.py          # все сценарии
python docs/prototype/tests/run_tests.py 05 07    # выборочно, по префиксу файла
```

| Сценарий | Что проверяет |
|---|---|
| `01-letters-tips-settings-retry` | Письма и советы учитываются отдельно; «Отменить изменения» возвращает к последнему сохранению; «Повторить» помнит вакансию |
| `02-edge-cases` | Дубли `id`, переключение версий, блокировка кнопок во время выполнения, словарь и провайдер при сохранении и отмене |
| `03-run-buttons-strip-service-fields` | Полоса покрытия — одна остановка Tab и стрелки; кнопки, появившиеся во время выполнения, недоступны; служебные поля не запоминаются |
| `04-vacancies-59` | 59 вакансий, счётчики фильтров, реальные версии писем и советов |
| `05-resume` | Экран «Резюме», устаревшее сравнение, режим «резюме не найдено», замена файла и проверка формата |
| `06-saved-settings-and-fetch-panel` | Модели версий, команды берут сохранённые настройки, нет ключа LLM, `--no-llm`, панель сбора из профиля |
| `07-console-states` | Консоль: выполнение, отмена, ошибка, готово, повтор; кнопка «Закрыть» |
| `08-cv-tips` | Версии советов, отметки AC 5.4, пробелы, чек-лист, предупреждения `cv-tips` |
| `09-fetch-history` | Вкладка «Выгрузки», анализ одной выгрузки, новая строка после сбора |
| `10-vacancy-match` | Соответствие вакансии резюме и пробелы в карточках |
| `11-ux-package` | Объём письма, навыки вне вакансий, уход из настроек, удаление навыка, мобильная шапка, вкладки стрелками |
| `12-vacancies-search-counts` | Счётчики фильтров «Вакансий» учитывают поиск: число на кнопке = строк после нажатия (`match=true`); «Найдено N из 59»; кнопки с нулём неактивны, выбранная остаётся выбранной. Ожидается: «банк» — 16 · 1 · 1 · 1, «аналитик» — 42 · 5 · 5 · 6, «zzz» — 0 и три неактивные кнопки |

Сценарии написаны в ходе обзоров прототипа: каждое исправление проверялось сценарием, и в конце все прогонялись заново. Сценарии `01`–`03` написаны раньше остальных, и часть значений в их выводе отражает позднейшие изменения прототипа — это ожидаемо:
- в `02` навык BPMN остаётся в словаре: удаление теперь требует подтверждения в диалоге, а сценарий его не подтверждает;
- у Кредитон одна версия письма, как в реальных файлах, а не две демо-версии;
- `tabStopsOverview=2` — полоса покрытия и выбранная вкладка рейтинга; остальные вкладки доступны стрелками.
