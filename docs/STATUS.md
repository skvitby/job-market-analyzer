## Ключевые решения

- **LLM:** Claude Haiku 4.5 для обеих задач (`vacancy_analysis`, `cv_processing`) — [ADR-001](adr/001-llm-provider.md). Для писем и советов по резюме Sonnet 5.5 заметно точнее (письмо ~$0,04 против ~$0,01; советы — порядка $0,07 против ~$0,01 за вакансию), но пока не переключаем; для важного отклика `cv_processing` можно разово переключить на `claude-sonnet-5-5`.
- **Ollama:** схема ответа передаётся через `json_schema`; для писем нужен `qwen3-4b-8k` (запрос ~4,4K токенов). Модель 4B для писем не подходит (пересказывает цитаты, ломает грамматику); в US-03 искажает ID вакансий (бэклог, п. 15).
- **Промпты писем и советов больше не «уговариваем»:** правки промпта у Haiku 4.5 дают эффект меньше разброса между запусками. Эксперименты — по одной переменной, через `eval_cover_letters.py`.
- **Сроки в письме и советах:** округлять можно без завышения («более 6 лет», «почти 12 лет»), стаж — только к своей роли; результаты — как в резюме (AC 4.3, AC 5.3).
- **Проверки ответов LLM — кодом, а не доверием:** цитаты сверяются с резюме (AC 3.3, AC 4.6, AC 5.4), требования «без подтверждения» и термины советов — со словарём навыков, числа советов — с резюме.
- **Советы по резюме не правят резюме:** автоправка `my_cv.md` вне объёма US-05 — ручная правка остаётся последним фильтром от приукрашивания.
- **Сравнение с резюме:** навыки словаря — только точный поиск; навыки вне словаря — LLM с проверкой цитаты.
- **Отчёты, письма и советы оформляются под Obsidian** (callout-блоки, чек-листы, `[[#ссылки]]`); личные данные из резюме в git не попадают (`.gitignore`).
- **Вывод CLI — всегда UTF-8** (Q15): иначе при запуске не из окна консоли кириллица искажается, а на «→» команда падает.
- **Регионы:** пока работаем только с Беларусью (`--region 16`).
- **Веб-интерфейс (US-06):** локальный сервер только на `127.0.0.1` (`python -m src.cli web`, порт `8765`), один пользователь без авторизации; интерфейс вызывает те же функции, что CLI, и читает те же файлы; для экранов команды будут сохранять рядом с Markdown машиночитаемый `.json`; ключи `.env` — только статусом; замена резюме — с копией `my_cv.md.bak`.
- **Прототип — на реальных данных, личное — демо:** цифры рынка и вакансии публичные, текст резюме и писем в прототип не попадает.

## Как работаем

Правила процесса хранятся в памяти Claude Code и в `D:\AI\CLAUDE.md`; главное:
