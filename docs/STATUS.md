## Ключевые решения

- **LLM:** по умолчанию Claude Haiku 4.5 для обеих задач (`vacancy_analysis`, `cv_processing`); поддерживаются DeepSeek, Qwen, локальная Ollama (скачана `qwen3:4b-instruct-2507-q4_K_M`) — [ADR-001](adr/001-llm-provider.md).
- **Сравнение с резюме:** навыки словаря — только точный поиск; навыки вне словаря — LLM с проверкой цитаты.
- **Отчёты оформляются под Obsidian** (callout-блоки, `[[#ссылки]]`); в Zed ссылки не кликаются, Confluence Markdown не отображает — нужен отдельный экспорт.
- **Регионы:** пока работаем только с Беларусью (`--region 16`); по РФ описания не загружены (~835 вакансий, ~45 мин) — по решению пользователя.
