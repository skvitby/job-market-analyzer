## Ключевые решения

- **LLM:** Claude Haiku 4.5 для обеих задач (`vacancy_analysis`, `cv_processing`) — [ADR-001](adr/001-llm-provider.md). Для писем Sonnet 5.5 заметно точнее (~$0,04 против ~$0,01 за письмо), но пока не переключаем; для важного отклика `cv_processing` можно разово переключить на `claude-sonnet-5-5`.
- **Ollama:** схема ответа передаётся через `json_schema`; для писем нужен `qwen3-4b-8k` (запрос ~4,4K токенов). Модель 4B для писем не подходит (пересказывает цитаты, ломает грамматику); в US-03 искажает ID вакансий (бэклог, п. 15).
- **Промпт письма больше не «уговариваем»:** правки промпта у Haiku 4.5 дают эффект меньше разброса между запусками. Эксперименты — по одной переменной, через `eval_cover_letters.py`.
- **Сроки в письме:** округлять можно без завышения («более 6 лет», «почти 12 лет»), стаж — только к своей роли; результаты — как в резюме (AC 4.3).
- **Проверки ответов LLM — кодом, а не доверием:** цитаты сверяются с резюме (AC 3.3, AC 4.6), требования «без подтверждения» — со словарём навыков.
- **Сравнение с резюме:** навыки словаря — только точный поиск; навыки вне словаря — LLM с проверкой цитаты.
- **Отчёты и письма оформляются под Obsidian** (callout-блоки, чек-листы, `[[#ссылки]]`).
- **Регионы:** пока работаем только с Беларусью (`--region 16`).
